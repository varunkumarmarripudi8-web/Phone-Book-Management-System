\# Phone Book Management System



\## About the Project

The Phone Book Management System is a Java web application for managing contacts. Users can register, log in, add contacts, view contacts, edit contact details, and delete contacts.



\## Technologies Used

\- Java

\- Servlets and JSP

\- JDBC

\- MySQL

\- HTML and CSS

\- Bootstrap

\- Apache Tomcat



\## Features

\- User registration and login

\- Add new contacts

\- View saved contacts

\- Edit contact details

\- Delete contacts

\- Logout functionality



\## Project Structure

\- `src/main/java/p1/` — Java Servlets, DAO classes, and beans

\- `src/main/webapp/` — JSP pages and web resources

\- `src/main/webapp/WEB-INF/` — Web configuration and required libraries



\## Database Setup

Create a MySQL database named `phonebook`. Configure your local database connection using the example file `src/main/java/p1/DBConnect.java.example`. Rename it to `DBConnect.java` and update the database URL, username, and password for your local environment.



\*\*Note:\*\* Do not commit real database credentials to a public repository.



\## How to Run

1\. Install Java, Apache Tomcat, and MySQL.

2\. Import the project into Eclipse.

3\. Configure the MySQL database and connection details.

4\. Deploy the application to Tomcat.

5\. Open the application in your browser.
